WHAT IT DOES

A task tracker that lives where you work

Notes are stored in a single project asset — never as components on your GameObjects. Your prefabs, builds and Git diffs stay clean.

Badges & tints in the Hierarchy

TODO, WIP, Broken and Final statuses color-code your rows. Hover the note icon to read the full note, click to edit. Colors are fully customizable.

Floating labels in the Scene View

Notes stay visible next to their objects — no selection needed. Drag labels to reposition them, with a leader line back to the object.

One Overview panel

Every note in the project, grouped by scene and prefab. Filter by status, search, ping the object, edit or relink — your TODO list, clickable.

Prefab Mode & orphan recovery

Annotate inside Prefab Mode. Notes survive prefab conversion thanks to safe auto-relink, and orphaned notes can always be relinked manually.

Full Undo support

Every operation — create, edit, delete, move, relink — is undoable with Ctrl+Z, like any native Unity action.

Team-friendly storage

All notes live in one ScriptableObject asset. Commit it to share notes with your team; visual preferences stay per-user.

GET STARTED

Up and running in two minutes

01 · IMPORT

Import the package from the Asset Store. Everything lives in an Editor folder — nothing ships in your build.

02 · ANNOTATE

Right-click any GameObject → Hierarchy Notes → Add or Edit Note (or Ctrl+Shift+N). Type a note, pick a status, done.

03 · TRACK

Open Window → Hierarchy Notes → Overview to see every note in the project. Filter on TODO and work through the list.

Settings live in Edit → Preferences → Hierarchy Notes — colors, Scene View labels, auto-relink and more. Full details in the documentation.
